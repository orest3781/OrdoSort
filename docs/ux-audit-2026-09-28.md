# UX audit — every screen (2026-09-28)

Three read-only reviewers ran the ux-design checklist over all 24 windows and views. They used screenshots rendered that day (both themes) and the E2E evidence run `evidence/20260928-171806`. The three Critical findings were then checked against the code by hand. Findings that repeat across windows appear once, with every window they affect.

Already fixed that day, not repeated here: the Unlock window's four Major items (`fix/unlock-ux`).

Contrast is out of scope: `ThemeTests.TextPairs` enforces AA for the theme tokens.

| ID | Screen | What goes wrong | Law | Fix | Status |
