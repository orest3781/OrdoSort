# UX audit — every screen (2026-09-28)

Three read-only reviewers ran the ux-design checklist over all 24 windows and views, using screenshots rendered that day (both themes) and the E2E evidence run `evidence/20260928-171806`.

A second pass the same day then did three things:
- **Checked every Critical and Major against the code:** a fresh reviewer tried to disprove each one; the Criticals were also checked by hand.
- **Rendered all 20 registered windows** (light, dark, and 18px at minimum width), covering the screens never seen before: the Password prompt, the date prompt, Standardise names, the message box and all seven Settings tabs.
- **Walked every window with Tab.**

Findings that repeat across windows appear once, with every window they affect.

Out of scope:
- The Unlock window's four Major items, already fixed that day (`fix/unlock-ux`).
- Contrast, which `ThemeTests.TextPairs` enforces for the theme tokens.
